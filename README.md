# Technical books by Robert Petrušić

This collection brings together English-language technical books and development plans by inventor Robert Petrušić of Ploče, Croatia. The editions document working ideas, proposed systems, design decisions, test plans and the limits of the available evidence.

## Reading the editions

The PDF and DOCX files preserve the supplied Google Docs editions. The Markdown files are derived from those sources; their original images are stored alongside them for browsing on GitHub. Layout and page breaks can differ between formats and reading software. Some original PWS illustrations retain Croatian labels.

The books distinguish physical evidence from proposals and assumptions. Inclusion in this collection does not by itself establish that a system has been built, certified or independently validated. Consult the individual edition for its stated evidence and limitations.
